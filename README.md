# ULTRON CODE

Hybrid Autonomous AI Development Orchestrator

ULTRON CODE coordinates software development across AI coding tools such as ChatGPT, Claude, Cursor, and local development environments.

## Vision

Provide a project goal once, decompose it into phases, monitor development progress, validate repository changes, and prepare the next instruction for an AI coding tool.

## Core Principles

- Human-in-the-loop by default
- API-first integrations where available
- Screen automation only as a controlled fallback
- Repository and test-based verification
- Explicit approval for risky actions
- Persistent project and phase state
- Complete audit logging

## Planned Capabilities

1. Project and goal management
2. Phase and task planning
3. Provider adapter architecture
4. Screen and window monitoring
5. Response extraction and analysis
6. Git and terminal inspection
7. Validation and test execution
8. Next-prompt generation
9. Keyboard automation with approval gates
10. Audit logs and recovery

## Initial Development Strategy

The project will be developed incrementally, beginning with a stable domain model and local orchestration engine before adding screen automation and external provider integrations.

## Safety

ULTRON CODE must not blindly execute destructive commands, handle secrets automatically, bypass security controls, or continue indefinitely without configurable limits and stop controls.

## Status
